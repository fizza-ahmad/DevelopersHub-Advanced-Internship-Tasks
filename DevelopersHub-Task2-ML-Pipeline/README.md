# End-to-End ML Pipeline for Customer Churn Prediction

## Objective

Build a reusable machine learning pipeline using Scikit-learn Pipeline API to predict customer churn.

## Dataset

Telco Customer Churn Dataset

## Steps

- Data Loading
- Data Cleaning
- Feature Encoding
- Feature Scaling
- Logistic Regression
- Random Forest
- GridSearchCV
- Model Evaluation
- Model Export using joblib

## Technologies

Python
Pandas
Scikit-learn
Joblib

## Results

Successfully created an end-to-end production-ready ML pipeline and exported the trained model.
